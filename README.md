# Lernendenberatung

Erfassung von Beratungsgesprächen und Sitzungen (Supervision / Intervision) für die Lernendenberatung der BFSU, mit Auswertung und Export ins Abrechnungsformular.

**Datenschutz:** Dieses Repository enthält nur das Programm. Die erfassten Einträge werden ausschliesslich auf dem jeweiligen Gerät bzw. im persönlichen OneDrive der Lehrperson gespeichert und nie an diesen Server übertragen. Es werden keine Namen von Lernenden erfasst.
